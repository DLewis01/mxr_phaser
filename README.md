# MXR phase 90
A software implementation of a MXR phaser 90
A phaser pedal creates a "swooshing" or swirling sound by splitting the audio signal, shifting the phase of part of it, and recombining them to produce moving peaks and notches in the frequency spectrum
  <p>      
I saw this video (https://www.youtube.com/watch?v=13ZSrCU6yZc) about David Gilmour and his signature sound, so I had to impliment the phaser to hear what it added to his playing.

I based the code from the circuit design, I transposed it back to first principles equations from the electronics, then used those equations to make a digital version.
